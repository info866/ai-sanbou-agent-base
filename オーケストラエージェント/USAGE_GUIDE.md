# AI統合オーケストラ — 利用ガイド

## これは何か

Claude Codeでテキストを入力するたびに、自動で「分類 → 計画 → 実行 → 評価」のパイプラインを走らせるシステムです。

## 使い方

### 新しいプロジェクトでオーケストラを使いたい場合

```bash
cp -r オーケストラエージェント/ あなたのプロジェクト/オーケストラエージェント/
```

**以上。** `.claude` のコピーもsetup.pyの実行も不要です。

Claude Codeを開いてテキストを入力すれば、自動的にオーケストラが動きます。

### なぜこれだけで動くのか

フックは `~/.claude/settings.json`（ユーザーのグローバル設定）に登録済みです。

```
あなたがClaude Codeで何か入力する
  ↓
グローバルフックが発火
  ↓
フックスクリプトがプロジェクト内を探索:
  「オーケストラエージェント/orchestrator.py」がある？
  ↓
  ある → オーケストレータ自動実行 → 結果をClaudeに注入
  ない → 何もしない（通常のClaude Codeとして動作）
```

つまり、`オーケストラエージェント/` フォルダの**有無だけ**がスイッチです。

### オーケストラを使わないプロジェクト

何もする必要はありません。`オーケストラエージェント/` フォルダがなければフックは何もせず `{}` を返します。通常のClaude Codeとして動作します。

## 具体例

### 例1: 新規プロジェクト「原価管理アプリ」

```bash
mkdir ~/プログラム開発/原価管理アプリ
cp -r ~/プログラム開発/AI統合オーケストラ/オーケストラエージェント ~/プログラム開発/原価管理アプリ/
cd ~/プログラム開発/原価管理アプリ
claude
```

→ テキストを入力するだけでオーケストラが自動実行される。

### 例2: 既存プロジェクト「FX自動売買プログラム」

```bash
cp -r ~/プログラム開発/AI統合オーケストラ/オーケストラエージェント ~/プログラム開発/FX自動売買プログラム/
```

→ 既存の `.claude/settings.json` には一切触らない。フォルダを置くだけ。

### 例3: オーケストラが不要になった

```bash
rm -rf ~/プログラム開発/原価管理アプリ/オーケストラエージェント
```

→ フォルダを消すだけ。次回からフックは自動スキップされる。

## グローバルフックの設置場所

```
~/.claude/
├── settings.json                          ← フック登録済み
└── hooks/
    └── orchestra/
        ├── user_prompt_hook.py            ← 毎回のテキスト送信時
        └── session_start_hook.py          ← Claude Code 起動時
```

この設定は全プロジェクト共通で、一度設置すれば触る必要はありません。

---

## 動作確認

テキストを送信した後、Claudeの応答の上に以下が表示されていれば動いています:

```
UserPromptSubmit hook additional context:
## オーケストラ自動フック（UserPromptSubmit）
以下は orchestrator.py の実行結果（JSON）です。
...
```

| 状態 | 意味 |
|------|------|
| 上記が表示される | オーケストラ動作中 |
| 何も表示されない | オーケストラ未検出（フォルダが存在しないか、パスが違う） |

動かない場合は Claude Code を一度再起動してください（`/exit` → `claude`）。
